# 中大校園快報（NCU Resilience AI）｜課程專題

AI 知行合一期末專題，第一組；同時參加 Microsoft × NCU AI Innovation Demo Day。

這個 repo 放的是我在本課負責的工作：規格整理、問卷與驗證、簡報與發表。

## 平台來源

「中大校園快報」平台由另一門課的團隊開發，平台原始碼不在這個 repo。本課的分工已向助教說明。

平台功能：把學校公告、新聞、社群與匿名回報中的校園事件，由 AI 整理成快報、歸成系列，並追蹤學校的改善措施。主案例是**腳踏車失竊**。詳細規格見 [spec.md](spec.md)。

## 我在本課負責的部分

| 工作 | 內容 | 放在哪裡 |
| --- | --- | --- |
| 規格整理 | 依計畫書、W8 講評、競賽辦法與平台實際功能，整理系統規格與專題規劃 | `spec.md`、`docs/plan.md` |
| 問卷 | 腳踏車失竊問卷的題目、去識別化資料與分析 | `survey/` |
| AI 驗證 | 用真實樣本檢查平台 AI 的擷取、分類、事件合併是否正確，並和人工整理比較 | `eval/` |
| 驗收測試 | 依 spec 第 11 節驗收條件 A1–A11 實測，記錄發現的問題並回報開發團隊 | `docs/test-log.md` |
| 簡報與發表 | 參賽簡報、Demo 影片、3 分鐘講稿 | 繳交時另附 |

## 檔案結構

```
├── README.md          # 本檔
├── spec.md            # 系統規格
├── docs/
│   ├── plan.md        # 專題規劃：競賽、課程、時程、驗證計畫
│   ├── ai-log.md      # AI 協作紀錄
│   └── test-log.md    # 測試與除錯紀錄
├── survey/            # 問卷題目、去識別化資料、分析程式（原始資料在 raw/，不上傳）
└── eval/              # 標註樣本、比對程式、正確率報告
```

## 資料與隱私

- 問卷不收姓名、學號、聯絡方式；原始資料放在 `survey/raw/`，已列入 `.gitignore`，不上傳。
- 本 repo 不放平台的帳密、API 金鑰或原始碼。
- 平台示範站使用虛構資料，示範站的數字不當作問題證據或成效。
